# Caption-Action 0.3.27 — cascade audit

## 1. Changes made
- **Home Input language:** Replaced passthrough chips/summary/hint with a single **Input language (from)** spinner (`Languages.all`), bubble style matching Target. **Target language (to)** unchanged.
- **Settings:** `AppSettings.inputLanguage` (default `en`); DataStore key `input_lang`. Migrate from legacy `passthrough` once (single code → that lang, else `en`). Stop writing product passthrough sets (`passthrough=""`); `passthroughLanguages` stays empty/deprecated.
- **Live ASR (critical):** `CaptionOverlayService` calls `activeEngine.setSourceLanguage(settings.inputLanguage)` before every `transcribeWindow` (and at engine setup). Whisper → `language=<input>`, `translate=false`, mode `mic-source-<code>` (same as Mic From).
- **ASR-only when input==target:** no MT; dual switch hidden/unavailable.
- **Dual:** enabled when `input≠target` **and** engine supports dual **and** user switch on.
- **MT packs:** `ensureMtPacks` / overlay `ensureModels` use `extraSources = setOf(inputLanguage)`.
- **`MlKitTranslationEngine.applyPolicy`:** skip when `inputLanguage==targetLanguage`; prefer `inputLanguage` as MT source when set (Live captions tagged from Whisper source).
- **Mic Translator:** From/To prefs independent; `extraSources` uses From + Home `inputLanguage` (no passthrough set). FIFO / `translateExplicit` / junk filters **untouched**.
- Removed/updated passthrough product strings; dual hint mentions input≠target.
- versionName `0.3.27`, versionCode **50**.
