# Caption-Action 0.3.26 — cascade audit

## 1. Changes made
- **Mic short-phrase MT (all From≠To pairs):** `MlKitTranslationEngine.translateExplicit(text, sourceLang, targetLang)` — picker From→To, no language-id guess, **does not** call `hasEnoughContentForMt` (Live crumb gate intact). Allows ≥1 letter token after strip punct/diacritics/¡¿ (Latin len ≥2, CJK ≥1) via `AsrJunkFilter.hasEnoughContentForExplicitMt`.
- **MicTranslatorActivity:** From≠To uses `translateExplicit` (publish ASR, then revise); null → keep ASR. Music/meta/junk skip before publish.
- **AsrJunkFilter:** `isMusicOrSoundTag`, `isWhisperMetaLine` (e.g. speaking in foreign language), `hasEnoughContentForExplicitMt`, `stripDiacriticsForLength`. Wired into `isJunk` → `sanitizeOrNull` (Live + Mic ASR engines).
- **Mic From=zh (and all non-en):** Whisper already `setSourceLanguage(from)` → `language=<from>`, `translate=false` (`mic-source-*`). Confirmed unchanged. If Tiny still emits EN meta for CJK audio, meta is suppressed (must not publish).
- **From/To wheel UI:** labels 14sp bold; NumberPicker scrolled names ~16sp bold (`applyPickerTextStyle`); bare Apple-style (no card); row 118dp.
- versionName `0.3.26`, versionCode **49**.

## 3. Why Live `hasEnoughContentForMt` unchanged
Live MediaProjection windows often emit short crumbs that MT turns into nonsense targets. Keeping the ≥2-token / ≥6-letter (CJK ≥2) gate protects the overlay. Mic has an explicit From picker and intentional short utterances (greetings), so it uses `translateExplicit` + `hasEnoughContentForExplicitMt` instead of softening the Live gate.

## 4. Mic From language → Whisper (verified)

Product rule: AI cannot listen to all languages at once — Mic must tell Whisper which one.

| Check | Evidence | Result |

| Mic never `language=auto` while From set | Explicit branch precedes `useEnDirect` / `auto-translate-en` / `auto-mlkit` | **PASS** |
| Live overlay remains auto | `CaptionOverlayService` has **zero** `setSourceLanguage` calls; Whisper `sourceLanguage=""` | **PASS** — Live auto/en-direct unchanged |
| Log mode pattern | `lastMode = "mic-source-$explicitSource"` e.g. **`mic-source-zh`**, `mic-source-ja`, `mic-source-es` | Mic emit log includes `mode=mic-source-zh` |
| Chinese meta still possible from Tiny | `isWhisperMetaLine` + `isJunk` + Mic pre-publish skip; lang still forced `zh` | Meta never published; lang=zh kept |
