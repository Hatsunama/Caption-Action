# Caption-Action 0.3.25 — cascade audit

## 1. Changes made
- Mic Translator: Apple-style bare NumberPicker From/To wheels under mic (`Languages.all`, ≤~110dp / <¼ screen); labels "from"/"to"; ScrollView bottom margin 220dp.
- Persist mic From/To in SharedPreferences `mic_translator` (`mic_from` / `mic_to`); defaults from=`en`, to=Home `targetLanguage` (or en).
- `InferenceEngine.setSourceLanguage(code)` — empty = auto (Live); non-empty = explicit ASR lang.
- `WhisperCppInferenceEngine`: when source set → `language=<from>`, `translate=false` (`mic-source-*`); empty source keeps Live auto / en-direct bias path. Old mic-en-direct bypassed when source set.
- Mic loop: `setSourceLanguage(from)`, `setTargetLanguage(to)`; skip MT when from==to; else ML Kit `applyPolicy` with `settings.copy(targetLanguage=to)`.
- Sherpa: stores sourceLanguage (SenseVoice load still auto — stub).
- CaptionOverlayService: **does not** call `setSourceLanguage` (stays auto).
- AudioCapture FIFO / `drainToNewestWindow`: **unchanged**.
- versionName `0.3.25`, versionCode 48.

## 3. Live playback path: UNCHANGED — evidence
- `CaptionOverlayService`: still `drainToNewestWindow` + `setPlaybackCapture(true)` + `forceFlush=true`; **no** `setSourceLanguage` call → Whisper `sourceLanguage=""`.
- Whisper empty-source branch: `en-direct` / `auto-translate-en` / `auto-mlkit` identical to 0.3.24 Live behavior.
- `FLUSH_AT_PLAYBACK`, `PLAYBACK_*` RMS, threads=6 untouched.
- Home Languages target spinner still only feeds Live / Home settings.

## 4. Mic From/To contract
| Concern | Behavior |
|---|---|
| Whisper source | Mic sets `setSourceLanguage(from)` every window → `language=from`, `translate=false` |
| MT target | `setTargetLanguage(to)` + `applyPolicy(..., settings.copy(targetLanguage=to))` |
| from==to | ASR only; skip ML Kit |
| Picker change while mic on | Next FIFO window reads volatile from/to |
| Live | source unset → auto |
